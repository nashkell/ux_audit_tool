# Usability Heuristics Checklist

## 1. Visibility of System Status
- [ ] Loading indicators present
- [ ] Progress shown for multi-step
- [ ] Action feedback immediate
- [ ] Current state/location clear
- [ ] Errors visually distinct

## 2. Match System & Real World
- [ ] Plain language (no jargon)
- [ ] Icons match mental models
- [ ] Logical information order
- [ ] Familiar terminology

## 3. User Control & Freedom
- [ ] Undo available
- [ ] Cancel buttons present
- [ ] Easy modal dismissal
- [ ] Back navigation works
- [ ] Confirmation before destructive

## 4. Consistency & Standards
- [ ] Navigation consistent
- [ ] Terminology consistent
- [ ] Visual styling consistent
- [ ] Platform conventions followed

## 5. Error Prevention
- [ ] Input constraints/validation
- [ ] Good defaults provided
- [ ] Confirmation for big actions
- [ ] Disabled states prevent errors

## 6. Recognition vs Recall
- [ ] Options visible
- [ ] Context preserved
- [ ] Recent items shown
- [ ] Instructions in-context

## 7. Flexibility & Efficiency
- [ ] Keyboard shortcuts
- [ ] Search effective
- [ ] Multiple paths available
- [ ] Personalization options

## 8. Aesthetic & Minimalist
- [ ] Content focused on essentials
- [ ] Clear visual hierarchy
- [ ] No distracting decoration
- [ ] Primary actions prominent

## 9. Error Recovery
- [ ] Errors in plain language
- [ ] Specific problem identified
- [ ] Solution suggested
- [ ] Positioned near problem

## 10. Help & Documentation
- [ ] Help easily accessible
- [ ] Searchable docs
- [ ] Task-focused content
- [ ] Contextual tooltips

---

## Scoring: 1-5 per heuristic (5=excellent, 1=critical issues)
