# WCAG 2.1 AA Accessibility Checklist

## Perceivable

### Text Alternatives
- [ ] Images have descriptive alt text
- [ ] Decorative images have empty alt
- [ ] Icons have accessible names

### Contrast
- [ ] Body text: 4.5:1 minimum
- [ ] Large text (18pt+): 3:1 minimum
- [ ] UI components: 3:1 minimum

### Adaptable
- [ ] Content order logical without CSS
- [ ] Instructions not sensory-dependent
- [ ] Works in any orientation

---

## Operable

### Keyboard
- [ ] All functions keyboard accessible
- [ ] No keyboard traps
- [ ] Focus indicator visible
- [ ] Logical focus order

### Navigation
- [ ] Skip links present
- [ ] Descriptive page titles
- [ ] Multiple ways to find pages
- [ ] Descriptive link text

### Touch
- [ ] Touch targets 44x44px minimum
- [ ] Adequate spacing between targets

---

## Understandable

### Readable
- [ ] Page language defined
- [ ] Reading level appropriate
- [ ] Abbreviations defined

### Predictable
- [ ] Focus doesn't change context
- [ ] Consistent navigation
- [ ] Consistent identification

### Input Assistance
- [ ] Errors identified clearly
- [ ] Labels/instructions provided
- [ ] Error suggestions offered

---

## Quick Tests

### Keyboard Test
1. Tab through entire page
2. All interactive elements reachable?
3. Focus visible at all times?
4. Can escape all modals?

### Zoom Test
1. Zoom to 200%
2. Content still readable?
3. No horizontal scroll?

### Color Test
1. View in grayscale
2. Information still clear?
3. Links distinguishable?
